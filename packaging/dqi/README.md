# dqi

DQI is the Deployment Quality Index, a specification for scoring whether an AI system
is fit to be put into service.

This package is an alias. It installs [Touchstone](https://github.com/Quantile-Labs/touchstone),
the tool that computes DQI, and the command you want is `touchstone`.

```bash
pip install dqi
touchstone --help
```
